# All Space Catalog
All Space Catalog (ASC) is an open-source astronomical database designed to explore, categorize, and archive the wonder of our universe—from our local Solar System to distant galaxies and cosmic anomalies.

Visit the website here:
https://awakristal.github.io/all-space-catalog/

# All SpaceCatalog
All Space Catalog (ASC) es una base de datos astronómica de código abierto, diseñada para explorar, categorizar y archivar las maravillas de nuestro universo: desde nuestro sistema solar local hasta galaxias distantes y anomalías cósmicas.

Visita el sitio web aquí:
https://awakristal.github.io/all-space-catalog/
